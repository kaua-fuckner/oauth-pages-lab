EVIDÊNCIA 04 — ESQUEMA DO D1

Projeto: oauth-pages-lab

Banco utilizado:
Cloudflare D1

Binding:
DB

Tabelas utilizadas:

1. oauth_transactions

Colunas:

* id_hash TEXT PRIMARY KEY
* provider TEXT NOT NULL
* state_hash TEXT NOT NULL
* nonce TEXT
* code_verifier TEXT NOT NULL
* expires_at INTEGER NOT NULL

Índice:
oauth_transactions_expiry ON expires_at

2. sessions

Colunas:

* id_hash TEXT PRIMARY KEY
* issuer TEXT NOT NULL
* subject TEXT NOT NULL
* email TEXT
* display_name TEXT
* expires_at INTEGER NOT NULL
* created_at INTEGER NOT NULL

Índice:
sessions_expiry ON expires_at

Finalidade:

A tabela oauth_transactions armazena temporariamente os dados necessários para validar o fluxo OAuth, incluindo state, nonce e code_verifier.

A tabela sessions armazena as sessões locais dos usuários autenticados, permitindo controle de expiração e revogação das sessões.

Resultado:
D1 CONFIGURADO E UTILIZADO PELA APLICAÇÃO.
