EVIDÊNCIA 03 — RETORNO DO GITHUB

Projeto: oauth-pages-lab

Provedor: GitHub

Callback configurado:
https://oauth-pages-lab-bvt.pages.dev/oauth/callback/github

Fluxo testado:

1. Usuário inicia o login pelo GitHub.
2. O GitHub autentica o usuário.
3. O GitHub redireciona para o callback configurado.
4. A aplicação valida o retorno OAuth.
5. A transação OAuth é consumida.
6. Uma sessão local é criada no D1.
7. O usuário autenticado pode consultar /api/me.

PKCE utilizado:
S256

Também são utilizados state e nonce para proteção do fluxo OAuth.

Resultado:
LOGIN COM GITHUB FUNCIONANDO.
